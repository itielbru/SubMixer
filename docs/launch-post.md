# פוסט השקה (טיוטה מוכנה להדבקה)

מתאים לקבוצות פייסבוק או פורומים של כתוביות, Plex/Kodi וסרטים בישראל.

---

**כלי חינמי לסנכרון כתוביות בעברית והטמעתן בסרט (Windows)**

נמאס מכתוביות שמקדימות או מאחרות, או מג'יבריש במקום עברית?
בניתי את **SubMixer**, תוכנה חינמית בקוד פתוח שעושה את זה בחלון אחד ובעברית:

- פותחים סרט (MKV/MP4) וגוררים פנימה קובץ כתוביות (SRT/VTT/ASS)
- קידוד עברי (windows-1255) מזוהה אוטומטית, בלי ג'יבריש
- מסנכרנים: הזזה, תיקון קצב (הפרשי 23.976/25 fps), סנכרון ויזואלי או סנכרון אוטומטי לפי האודיו
- שומרים SRT מסונכרן, או מטמיעים את הכתוביות בקובץ MKV/MP4 עם בחירת מסלולי אודיו וכתוביות
- אפשר גם "לצרוב" את הכתוביות לתוך התמונה, בשביל טלוויזיות שלא קוראות כתוביות

הורדה: https://github.com/itielbru/SubMixer/releases/latest
(התוכנה לא חתומה דיגיטלית, לכן Windows עשוי להזהיר: More info → Run anyway)

אשמח מאוד לפידבק: מה חסר, מה לא עבד, ואיך אתם מסנכרנים כתוביות היום.
